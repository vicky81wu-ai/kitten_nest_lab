Auth

Authentication type: API Key / Custom header

Header name: X-Nest-Token Header value: use the existing Nest write token

不要把 token 写进 repo、聊天、截图或公开页面。

Tool

operationId: update_text_target method: POST path: /api/set-state

Request shape

{ "textTarget": { "targetId": "coffeeCornerBubble", "mode": "publish", "text": "line 1\nline 2", "dryRun": false } }

Red lines

  1. 不要暴露任意 state path 写入。
  2. 只允许 text-target registry 里的 targetId。
  3. 粉本本 / archive / history / trash 需要单独动作，不混进日常气泡写入。
  4. 默认先 dry-run 再 publish，尤其是新 target。

Expected result

Actions/MCP 成功接入后，隔壁工具栏应出现一个类似下面的 callable tool：
