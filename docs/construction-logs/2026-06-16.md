# Construction log - 2026-06-16

## Topic

Unified text target naming and `/write` safety rollout.

## Accepted user rule

All writable text package tags must be explicit:

```text
roomOrScene + textType
```

Canonical tags now used for daily package writing:

```text
[coffeeCornerBubble]
[coffeeCornerLapCloseBubble]
[windowWeather]
[hubbyNote]
```

Deprecated / forbidden short or scene-only tags:

```text
[coffeeCorner]
[coffeeCornerLapClose]
[lapClose]
[lapCloseBubble]
[lapBubble]
```

Reason: scene names are not text targets, and short lap names will collide with future scene variants.
