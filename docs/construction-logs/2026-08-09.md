- v2 had copied the safe-area metadata but not the accepted 2026-06-19 canvas-fill contract. Its centered shell ended at `100dvh`, leaving a dark strip below the scene in iPhone standalone mode. The production shell now uses the original `100vh -> 100dvh -> 100lvh` cascade, a fixed full-screen canvas, and an absolutely filled stage. No safe-area color strip, background shift, hotspot coordinate, or room layout was added.

A first beach tap could join that in-flight request, exhaust the static and Storage timeouts, then work only after the app was reopened with a warm cache. There is no detached image loader.

State readiness now runs beside the ordered visual lifecycle.
