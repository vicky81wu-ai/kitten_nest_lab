## iOS long-press issue and fix

Observed issue:

```text
iOS/WebView showed blue selection handles and copy/query/translate bar during long press.
```

Attempted fix:

```text
-webkit-user-select: none
-webkit-touch-callout: none
preventDefault on long press
```

Regression:

```text
A global touchend guard accidentally blocked all hotspots.
Symptoms: left/right navigation, powder notebook, and admin long press became unreliable or dead.
```

Final fix:

```text
Only touches that start inside the upper-left admin zone may be blocked.
All other hotspot touchend/click behavior must pass through.
```
